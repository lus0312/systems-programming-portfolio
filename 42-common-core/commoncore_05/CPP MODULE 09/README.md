# CPP Module 09 - STL 활용

C++98 모듈 과제입니다. 이번 모듈의 핵심: STL 컨테이너를 과제 요구에 맞게 선택해 문제를 푸는 실습.

| 연습 | 내용 |
|---|---|
| ex00 | `BitcoinExchange`: 날짜별 환율 데이터로 값 계산 (`std::map`) |
| ex01 | `RPN`: 역폴란드 표기법 계산기 (스택) |
| ex02 | `PmergeMe`: Ford-Johnson(merge-insertion) 정렬, 컨테이너 2종 비교 |

## 빌드

각 `exNN` 폴더에서 `make`를 실행합니다 (`-Wall -Wextra -Werror -std=c++98`).
