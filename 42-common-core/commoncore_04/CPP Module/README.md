# CPP Module 00 ~ 04

C++98 입문 모듈 다섯 개입니다. 각 모듈 폴더 안의 `exNN`에서 `make`로 빌드합니다.

| 모듈 | 주제 | 연습 |
|---|---|---|
| 00 | 네임스페이스, 클래스, 입출력 | `megaphone`, `PhoneBook`/`Contact` |
| 01 | 메모리 할당, 포인터·참조, 멤버 함수 포인터 | `Zombie`(스택/힙, 배열), 참조·포인터 비교, `HumanA/B`+`Weapon`, 파일 문자열 치환, `Harl` |
| 02 | 다형성(ad-hoc), 연산자 오버로딩, 정규 클래스 형식 | `Fixed` 고정소수점 (비교/산술/증감 연산자) |
| 03 | 상속 | `ClapTrap` → `ScavTrap`, `FragTrap` |
| 04 | 서브타입 다형성, 추상 클래스 | `Animal`/`Dog`/`Cat`, `Brain` 깊은 복사, 추상 클래스 |

## 핵심 개념

Orthodox Canonical Form(생성자·복사 생성자·대입 연산자·소멸자), 가상 함수와 가상 소멸자, 깊은 복사, 초기화 리스트

모듈 04는 `ex00`~`ex02`까지, 선택 과제(`ex03`)는 포함하지 않습니다.
